ScreenDrop V5 — fonctionnement

  • Raccourci global Shift + K.
  • Capture le moniteur situé sous le curseur.
  • Détecte le dernier onglet ChatGPT visité dans Chrome via UI Automation.
  • Colle l'image sans envoyer le message.
  • Préserve l'état de la fenêtre Chrome et revient vers l'application précédente.
  • Démarre automatiquement avec Windows et écrit un journal local de diagnostic.

Créer une commande

La commande est bien enregistrée, mais le débit réel ne peut être activé qu'après connexion d'un compte marchand / passerelle de paiement.
